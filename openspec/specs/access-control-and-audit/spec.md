## Requirements
### Requirement: 应用接口必须绑定可审计的认证会话
系统 MUST 为 Web 和 API 请求建立稳定的认证会话边界，并将时间线、搜索、详情、下载、导出、Provider 配置和隐私策略管理等接口绑定到可审计的主体身份，而不能依赖对象存储公开访问或“默认可信网络”假设。

#### Scenario: 未认证用户尝试访问照片库
- **WHEN** 一个未认证请求访问时间线、搜索或资产详情接口
- **THEN** 系统拒绝返回任何资产内容、缩略图访问句柄或敏感元数据

#### Scenario: 已认证用户访问自己的照片库
- **WHEN** 一个已建立有效会话的主体访问已授权的照片库接口
- **THEN** 系统基于该主体身份执行业务操作，并将后续敏感操作与该身份关联

### Requirement: 敏感操作必须经过授权和近期认证
系统 MUST 对整库导出、批量下载、Provider 配置变更、隐私策略变更、查看调试保留数据等高风险操作执行显式授权；对于足以造成大规模照片泄露或配置失陷的操作，系统 MUST 支持近期认证、显式确认或等价的二次校验。

#### Scenario: 会话已存在但最近未重新验证身份
- **WHEN** 用户尝试执行整库导出或修改 Provider 凭据
- **THEN** 系统要求其完成近期认证、显式确认或等价校验后才继续执行

#### Scenario: 无相应权限的主体尝试查看调试保留数据
- **WHEN** 一个普通会话请求访问原始 Provider 调试保留数据或审计明细
- **THEN** 系统拒绝该访问，并保留失败审计记录

### Requirement: 浏览器发起的变更请求必须防止跨站滥用
系统 MUST 对浏览器环境下的状态变更请求实施 CSRF 或等价的同站保护，并确保第三方页面不能借用现有会话静默触发导出、删除、配置修改或隐私策略变更。

#### Scenario: 恶意第三方页面尝试借用现有登录态触发导出
- **WHEN** 用户在已登录状态下访问了一个试图伪造导出请求的第三方页面
- **THEN** 系统因为缺少合法的同站凭据或变更令牌而拒绝该请求

### Requirement: 敏感操作必须产生不含秘密值的审计事件
系统 MUST 为登录、导出、批量下载、Provider 配置修改、隐私策略修改和调试保留访问等操作记录审计事件，并包含主体、动作、目标范围、结果、时间和来源信息；审计记录本身不得包含完整密钥、Token、预签名 URL、完整 OCR 文本或其他不必要的高敏感内容。

#### Scenario: 管理员修改对象存储配置
- **WHEN** 管理员成功更新主对象存储 Provider 的配置
- **THEN** 系统写入一条审计事件，说明是谁在何时修改了哪个 Provider、操作是否成功以及影响范围，但不会记录完整秘密值

#### Scenario: 导出请求被策略阻止
- **WHEN** 系统因为权限、策略或近期认证缺失而拒绝某次导出请求
- **THEN** 系统仍然记录一次失败审计事件，便于后续排查异常访问行为
