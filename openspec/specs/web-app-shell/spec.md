## Requirements
### Requirement: Web 顶层壳层必须提供清晰稳定的任务入口
系统 MUST 为已登录与未登录用户提供一致可理解的顶层导航，使用户能够明确进入照片浏览、照片导入和登录授权相关页面，并在当前页面中获得清晰的位置感。

#### Scenario: 用户从任意页面识别当前可执行任务
- **WHEN** 用户打开首页、导入页或登录页
- **THEN** 页面顶部导航与主标题会明确表达当前页面用途，并提供进入其他核心任务页面的直接入口

#### Scenario: 当前页面状态需要被明确标识
- **WHEN** 用户在顶层导航中浏览不同页面入口
- **THEN** 系统以可见的当前态样式标识正在访问的页面，避免用户失去位置感

### Requirement: 页面主文案必须以任务说明替代技术演示说明
系统 MUST 在首页、登录页和导入页中使用面向任务的标题、副标题、按钮文案和空状态说明，不得把底层认证、上传协议或联调说明作为页面主叙事。

#### Scenario: 登录页不再以认证术语作为主标题
- **WHEN** 用户进入登录页
- **THEN** 页面优先说明如何登录、登录后可做什么以及下一步去哪，而不是把 CSRF、Bearer Token 或 bootstrap 之类的机制作为核心文案

#### Scenario: 导入页不再以联调状态作为页面主说明
- **WHEN** 用户进入导入页准备上传照片
- **THEN** 页面优先说明上传步骤、前置条件和完成后的去向，而不是把对象存储直传、票据或调试信息作为首屏重点

### Requirement: 关键空状态与错误提示必须可操作
系统 MUST 为未登录、未选择库、未选择文件、没有搜索结果和请求失败等关键状态提供清楚的原因说明与下一步动作提示，而不是只返回技术错误或留空。

#### Scenario: 未登录用户访问照片首页
- **WHEN** 用户在没有有效会话的情况下打开首页
- **THEN** 系统显示需要先登录的说明，并提供前往登录页的直接入口

#### Scenario: 搜索或筛选没有结果
- **WHEN** 用户执行搜索或过滤后没有匹配资产
- **THEN** 系统显示无结果说明，并提示用户清空条件、切换筛选或去导入新照片
