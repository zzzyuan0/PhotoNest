## ADDED Requirements

### Requirement: 新上传资产在增强处理中也必须可被浏览和查看
系统 MUST 让已确认入库的资产在增强任务尚未全部完成时，仍然出现在总览、时间线和资产详情接口中，并明确返回处理中状态。

#### Scenario: 新上传图片尚未完成全部增强
- **WHEN** 用户上传一张图片、确认成功，但 Worker 仍在处理缩略图或识别任务
- **THEN** 总览、时间线和资产详情接口仍返回该资产，并标记其增强状态为处理中

### Requirement: 发现接口必须基于持久化资产事实返回查看句柄
系统 MUST 基于 PostgreSQL 中的资产与对象引用记录生成列表摘要、详情内容和受控查看句柄，而不是依赖 API 进程内存中的临时状态。

#### Scenario: 服务重启后查看最近上传的图片
- **WHEN** 用户在服务重启后打开最近上传图片的时间线卡片或详情页
- **THEN** 系统仍能根据持久化记录返回该资产的摘要信息、处理状态以及受控的预览或下载访问方式
