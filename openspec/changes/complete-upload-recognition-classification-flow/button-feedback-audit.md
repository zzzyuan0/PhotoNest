## 关键按钮盘点

### `apps/web/pages/login.vue`

| 按钮/入口 | 当前归类 | 说明 |
| --- | --- | --- |
| `先看看照片库` | 仅导航动作 | 只负责进入照片库，不触发请求。 |
| `查看导入流程` | 仅导航动作 | 只负责进入导入页。 |
| `读取当前会话` / `查看已有会话` / `再次检查会话` | 已接线动作 | 调用 `/api/v1/auth/session`，现已补充处理中和失败/成功提示。 |
| `登录并进入工作台` | 已接线动作 | 调用 `/api/v1/auth/login`，现已补充前置条件说明与成功反馈。 |
| `进入照片库` / `继续导入照片` | 仅导航动作 | 作为登录后的下一步入口。 |

### `apps/web/pages/import.vue`

| 按钮/入口 | 当前归类 | 说明 |
| --- | --- | --- |
| `去登录页` | 仅导航动作 | 跳转到登录页补齐前置条件。 |
| `查看照片库` / `导入后查看照片` / `前往照片库` | 仅导航动作 | 导向照片库；本次补充了导入完成后定位本轮资产的 query。 |
| `开始导入照片` | 已接线动作 | 会创建导入会话、申请上传票据、上传并确认入库。 |
| `继续导入` | 缺少局部反馈动作 -> 已补齐 | 现在通过结果卡片和状态文案说明可以继续下一批，不再只靠全局状态。 |

### `apps/web/pages/index.vue`

| 按钮/入口 | 当前归类 | 说明 |
| --- | --- | --- |
| `继续导入照片` / `管理登录状态` | 仅导航动作 | 负责跨页切换。 |
| `刷新照片库` | 已接线动作 | 调用时间线/地点/重复/相册接口；本次补充局部处理中与成功/失败反馈。 |
| `搜索结果` / `应用筛选` / `清空搜索` / `清空筛选` | 已接线动作 | 已接到搜索或时间线刷新；本次补充局部反馈。 |
| 地点卡片 | 已接线动作 | 会写入地点筛选并刷新时间线。 |
| 资产卡片 `加入收藏` | 已接线动作 | 调用 `/api/v1/assets/{assetId}/favorite`；本次补充卡片/详情区内联反馈。 |
| 资产卡片 `加入当前相册` | 已接线动作 | 调用 `/api/v1/albums/{albumId}/assets`；本次补充“未选择相册”近端反馈。 |
| `返回照片库` / `清空` | 已接线动作 | 前者切回时间线，后者清空当前选中详情。 |
| 详情区 `加入收藏` / `加入当前相册` | 已接线动作 | 与卡片动作同源；本次补充详情区内联反馈。 |
| `创建相册` | 已接线动作 | 调用 `/api/v1/albums`；本次补充创建中、成功、失败和空名称提示。 |
| 相册按钮 | 已接线动作 | 加载对应相册详情。 |
| `生成导出包` | 已接线动作 | 调用 `/api/v1/exports`；本次补充导出范围前置条件和就地反馈。 |

## 统一反馈模式

- 处理中：在触发区域附近显示“正在刷新… / 正在加入… / 正在生成导出包…”等动作级状态。
- 成功：使用局部 `alert-banner` 或卡片下状态文案确认动作已完成，并说明下一步可以做什么。
- 失败：错误信息优先绑定到当前动作区域，仍保留顶部全局错误作为兜底。
- 前置条件不足：在按钮附近说明缺少登录、library、文件或当前相册，而不是仅依赖禁用态。
